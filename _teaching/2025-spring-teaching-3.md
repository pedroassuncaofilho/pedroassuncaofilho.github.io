# Ementa de Disciplina

## Informações Gerais

| Campo | Descrição |
|-------|-----------|
| **Disciplina** | Cálculo Numérico |
| **Formação** | Básica |
| **Série/Período** | 5° |
| **Carga Horária** | 54h |
| **Pré-requisito** | - |
| **Regime** | Obrigatória |

## Ementa

Zeros de funções. Zeros de Polinômios. Sistemas de Equações Lineares. Inversão de Matrizes. Ajuste
de Curvas. Interpolação. Integração Numérica. Resolução Numérica de Equações diferenciais
ordinárias.
## Objetivo

Capacitar o aluno a utilizar ferramentas de Álgebra Linear para a resolução de problemas relacionados a Construção Civil.

## Critérios de Avaliação

### Instrumentos Avaliativos

| Instrumento | Quantidade | Pontuação | Peso |
|-------------|------------|-----------|------|
| **Avaliações** | 2 | 10,0 pontos cada | 100% |
| **Listas de Exercícios** | Contínuas | Complementar | - |

### Cálculo da Média Final

**Média Final = (Avaliação 1 + Avaliação 2) ÷ 2**

- **Aprovação**: Média Final ≥ 6,0
- **Recuperação**: 4,0 ≤ Média Final < 6,0
- **Reprovação**: Média Final < 4,0
